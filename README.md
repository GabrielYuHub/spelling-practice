# 英文单词拼写练习（spelling-practice）

给小学生用的英文单词拼写练习网页，主要在 iPad Safari 上使用。孩子选单词表后先看一遍单词列表，再按挖空提示拼写；家长在管理页维护单词表、孩子和学习记录。

## 主要功能

- **练习页**（`网站发布/index.html`）：多个孩子各自用 PIN 进入；4 种难度（自动、简单、进阶、听写）；自动朗读；答对后显示例句；今日复习（间隔复习）和错词本；每日打卡和徽章。
- **管理页**（`网站发布/editor.html`）：单词表按分组管理、文件导入、格式检查；孩子的 PIN、每日目标、最多尝试次数、每轮题数和可练习的分组；学习报表；导出备份与合并导入。

## 打包部署

```bash
cd 函数源码
./build.sh cloudbase <管理密码>   # 生成 CloudBase发布/app.zip，上传到 CloudBase 云函数 app
./build.sh edgeone <管理密码>     # 生成 网站发布/cloud-functions/api/app.js，随“网站发布”上传到 EdgeOne
```

第一次运行会自动安装依赖。打包生成的文件里写着管理密码，所以不放进仓库。**完整的部署步骤见 [部署步骤.md](部署步骤.md)**。

## 单词表格式

```
英文 [词性.] 中文释义 [| 例句 [| 例句翻译]]
## 分组名 单词表名                      ← 批量导入时，每个单词表以这样一行开头
school n. 学校 | I go to school every day. | 我每天去上学。
play sports 运动
Children, this is *James. 孩子们，这是詹姆斯。   ← 词前加 * 表示不挖空（人名、地名）
```

完整规则见需求文档第 5 章，或 `单词表编写提示词.md`。
